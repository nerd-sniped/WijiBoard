# WijiBoard Project

Welcome to the **WijiBoard** GitHub repository! This is your source for all files related to the WijiBoard.
## What is WijiBoard?

The **WijiBoard** is a remote-controlled interactive board that lets you move a planchette using WiFi and a web interface.

To see it in action, check out our [YouTube video](https://youtu.be/AgYoTsX05So)
